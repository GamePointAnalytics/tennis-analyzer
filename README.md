# tennis-analyzer

Analysis tool for tennis statistics, built with **Google AppSheet** (Frontend) and **Google Apps Script** (Backend).

## Repository Structure

- **`backend/`**: Google Apps Script code (managed via CLASP).
- **`frontend/`**: Documentation of AppSheet app definition, expressions, and views.
- **`data/`**: Schema definitions for the Google Sheets backend.
- **`docs/`**: Additional manuals and architecture diagrams.
